# 码脊 CodeSpine —— UI 设计决策（DESIGN）

> 记录评审过程中确定的视觉与交互规范，模板迭代以此为准。
> **原则：数据是 AI 的，样式是工程的，契约是 schema，守门是 audit。**

## 五视图导航

顶部标签栏，默认落在"变更概览"：

```
[变更概览] [影响链路] [代码差异] [独立变更] [验证情况]
```

### 变更概览（首页）

- 变更说明（meta.summary）
- 核心变更点（带阅读序号，可跳转到对应链路）
- 基线信息（基准分支 / 生成时间 / 文件分类统计）
- 评审关注点（人工标注的重点判断）
- 证据来源标识图例

### 影响链路

- 入口卡片横排（灰色 = 入口未变更，彩色 = 入口自身变更）
- 纵向调用链（精简/完整切换）
- **右栏双卡详情**：
  - 上卡 = 入口信息（URL 复制 / 入参 / 出口）
  - 下卡 = 类或块详情（路径/FQCN/检索串复制 + 关键代码 + 调用路径）
  - 未选中时显示虚线提示卡

### 代码差异

- **左右分栏**：左侧文件树（A/M + 文件名 + +N −M），右侧 diff 内容
- **函数级组织**：按方法分组，完整方法体渲染（从签名到 return + 闭括号）
- **方法块标题**：`文件名#函数名()  L起始-结束  N 处变更`
- **diff 行着色**：绿底 `+`（#dafbe1）、红底 `−`（#ffd8da）、上下文灰显
- **未变更折叠**：`⋯ N 行未变更 ⋯`（保留 diff 前后各 2 行上下文）
- **方法体最后 5 行永不折叠**
- **属性与导入独立分组**（📦 标识）
- 点击文件树切换右侧内容

### 独立变更

- 非链路变更独立卡片（文档/配置/枚举等）
- 全量文件索引（每个文件在哪条链的什么位置）

### 验证情况

- 验证项目列表（圆形图标：绿色✓已验证 / 黄色?待确认）
- 尚未覆盖范围（"未覆盖"标签）

## 证据来源标识

四级标识，渲染为彩色徽章：

| 标识 | 样式 | 含义 |
|---|---|---|
| 🟢 源码事实 | 绿底 | 可直接由代码或配置确认 |
| 🟡 分析推断 | 黄底 | 基于上下文得出的判断 |
| 🔴 待确认 | 红底 | 需要作者或评审者确认 |
| 🔵 已验证 | 蓝底 | 有执行结果及证据支持 |

## 术语规范

| 统一使用 | 禁止使用 |
|---|---|
| 变更点 | 病灶 |
| 精简链路 / 完整链路 | 只看脊痕 / 完整码脊 |
| 独立变更 | 未挂链 |
| 已省略 N 行 | 未变更 N 行 |
| 属性与导入 | — |

## 交互规范

| 交互 | 效果 |
|---|---|
| 点击链路中的类卡片 | 右栏下卡切换为类详情（路径复制 + 方法定位） |
| 点击链路中的逻辑块 | 右栏下卡切换为块详情（关键代码 + 调用路径） |
| 点击引用芯片（🔁） | 右栏下卡切换为引用详情（调用点 + 被调定义） |
| 点击代码差异中的任意行 | 复制 `路径:行号`，行闪绿反馈 |
| 点击方法块标题 | 折叠/展开方法体 |
| 概览核心变更点 | 跳转到对应链路视图 |
| 文件树标签 | 切换右侧 diff 内容 |

## 样式规范

- **颜色体系**：三色 + 琥珀（参数变更）
  - 绿 #1a7f37（新增）/ 蓝 #0969da（修改）/ 灰 #d0d7de（未变更）/ 琥珀 #9a6700（参数变更）
- **diff 配色**：GitHub 风格（绿底 #dafbe1 / 红底 #ffd8da / 上下文白底）
- **按钮**：描边式白底 + hover 变蓝，圆角 5px
- **图标**：验证状态用圆形 SVG 图标（✓ / ?），不用方形按钮
- **卡片头**：彩色背景条（入口=蓝 / 类详情=按类型着色 / 逻辑块=蓝左线 / 入参=绿）
- **代码块**：深色背景 #0d1117，行号列灰底分隔线

## 历史决策记录（为什么不这样设计）

| 被否决的方案 | 原因 |
|---|---|
| 泳道图 | 上来就是 service，看不懂；没有入口叙事起点 |
| "病灶"术语 | 评审是工程活动不是治病，投屏观感差 |
| 行号排序逻辑块 | 应按代码执行顺序（调用链行号字典序），不是文件物理行序 |
| 方法检测用宽松缩进匹配 | 会把 `xxx.add()` 语句误判为方法，导致方法体碎片化 |
| 内联代码片段在链路中 | 污染链路视图，改为点击块后在右栏按需展开 |
| 方形验证按钮 | 不像按钮，改为圆形图标 |
| 表格展示文件索引 | 改为卡片式行列表，更易扫读 |
| 无右栏的链路视图 | 用户需要点击查看详情和复制路径，右栏双卡不可省略 |
